# These documents are not the implementer's to edit

This folder holds the specification. It predates the code and outranks it.

**Implementer sessions** — anything writing code, tests or `PLAN.md` — do not
edit anything here: not to record what was built, not to reconcile a
discrepancy, not to tidy wording. If the code cannot satisfy a requirement, stop
and say so in `SPEC-QUESTIONS.md`. A specification edited to match an
implementation is no longer an independent account of the design, and the
reason for keeping it disappears.

**Changes come from a human or from the decider**, the role run by `/decide`
under the delegation recorded as `R-001` in `RULINGS.md`. The decider edits here
following `.claude/skills/decide/SKILL.md`, and every edit is a ruling in
`RULINGS.md`.

Read freely. Cite requirement and decision identifiers in commit messages.
