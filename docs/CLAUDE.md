# These documents are not yours to edit

This folder holds the specification. It predates the code and outranks it.

Do not edit anything here: not to record what was built, not to reconcile a
discrepancy, not to tidy wording. If the code cannot satisfy a requirement,
stop and say so. A specification edited to match an implementation is no
longer an independent account of the design, and the reason for keeping it
disappears.

Read freely. Cite requirement and decision identifiers in commit messages.
Changes to this folder come from a human.
